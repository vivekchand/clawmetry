## کانٹیکسٹ بلو آؤٹ، اور مانیٹرنگ کی قیمت

دو سوالات، جن کا جواب کسی بھی ایجنٹ موازنہ ٹول پر بھروسہ کرنے سے پہلے جاننا ضروری ہے۔

**یہ رن ٹائمز میں کانٹیکسٹ ونڈو بلو آؤٹ کو کیسے سنبھالتا ہے؟**

یوٹیلائزیشن فیصد اتنا ہی ایماندار ہوتا ہے جتنا کہ وہ عدد جس سے اسے تقسیم کیا جاتا ہے۔ ClawMetry ہر فراہم کنندہ کے حساب سے ونڈو کا سائز ایک ایسی [ٹیبل](clawmetry/context_windows.py) سے لیتا ہے جسے آپ پڑھ اور اس میں PR کر سکتے ہیں، جو Anthropic، OpenAI، Google، xAI، DeepSeek، Kimi، Qwen، Mistral، Llama اور GLM کا احاطہ کرتی ہے۔ یہ تمام 26 رن ٹائمز کو ایک ہی فراہم کنندہ کی پیمائش سے نہیں ناپتا۔ یہ اہم ہے: Anthropic کے 200K کے مقابلے میں ناپا گیا ایک 300K GPT-5 ٹرن ">100%، بلوون" پڑھا جائے گا جبکہ حقیقت میں وہ GPT-5 کے 400K کا 75% ہے۔ وہی پیمانہ ایک حقیقتاً اوور فلو شدہ 130K DeepSeek ٹرن کو ایک آرام دہ 65% کے طور پر چھپا دیتا ہے۔

ہر ونڈو اپنی اصلیت کے ساتھ آتی ہے: `model_table`، `explicit_marker`، `observed_floor`، یا جب ہمیں ماڈل معلوم نہ ہو تو ایک ایماندار `default`۔ اندازے پر بنایا گیا گیج کبھی بھی اتنی ہی ساکھ کے ساتھ ظاہر نہیں ہوتا جتنا کہ ایک لُک اَپ پر بنایا گیا۔

ClawMetry صرف کچھ رن ٹائمز پر کمپیکشن ایونٹس دیکھ سکتا ہے۔ اس لیے `GET /api/context-coverage` ہر رن ٹائم کے حساب سے بتاتا ہے کہ آیا **صفر کا مطلب "صاف چلا" ہے یا "ہم اندھے ہیں"**۔ ایک `0` جس کا مطلب حقیقت میں اندھا پن ہو، وہ ایسا ہی کہتا ہے۔ [مکمل تفصیل](docs/CONTEXT_BLOWOUT.md)

**اس آلہ کاری کی قیمت کیا ہے؟**

| راستہ | آپ کے ایجنٹ میں شامل | ڈیفالٹ؟ |
|---|---|---|
| سیشن-فائل ٹیلنگ (تمام 30 رن ٹائمز) | **0**۔ الگ پراسیس، آپ کے ایجنٹ میں کوئی ClawMetry کوڈ نہیں | آن |
| HTTP انٹرسیپٹر (`CLAWMETRY_INTERCEPT=1`) | ہر LLM کال پر **+0.44 ms**، یا ایک 5s کال کا 0.009% | آف |
| پری-ٹول ہک گیٹ (گرم کیش) | 36 ms کے انٹرپریٹر فرش کے اوپر، ہر گیٹڈ ٹول کال پر **+44 ms** | آف |
| نفاذی پراکسی (Enforcement proxy) | ہر LLM کال پر **+9.7 ms** | آف |

ڈیمن ہوسٹ کی قیمت: **2,762 ایونٹس/سیکنڈ** اِن جیسٹ، ڈسک پر **710 بائٹس/ایونٹ**
(100 ہزار ایونٹس کے لیے 67.7 MB)، اور ایک مصروف تنصیب پر مسلسل **ایک کور کا تقریباً 12%**۔ یہ آخری عدد ہمارے اپنے بتائے گئے 5-10% بجٹ سے زیادہ ہے، اس لیے اسے صفحے سے چھپانے کے بجائے ایک ایسے بگ کے طور پر شائع کیا گیا ہے جس کا پیچھا کیا جانا ہے۔

Apple M2 Pro پر `benchmarks/overhead.py` کے ساتھ ناپا گیا۔ ہارنس ہر حالت کو ایک الگ پراسیس میں چلاتا ہے، ان کی ترتیب بدلتا رہتا ہے، اور **جب راؤنڈز کسی عدد کے نشان پر متفق نہ ہوں تو اسے چھاپنے سے انکار کر دیتا ہے**۔ اسے اپنی مشین پر ایک منٹ میں چلائیں:

```bash
pip install clawmetry && python -m benchmarks.overhead
```

ہر راستہ ناپا جاتا ہے، بشمول ہک گیٹس اور نفاذی پراکسی، اور یہ ہارنس CI میں Linux، macOS اور Windows پر چلتا ہے۔ جاننے کے قابل دو نتائج: پراکسی Windows پر Linux کے مقابلے میں تقریباً سات گنا زیادہ قیمت لیتی ہے، اور ڈیمن فی الحال ایک کور کے تقریباً 12% کو مسلسل استعمال کرتا ہے، جو ہمارے اپنے 5-10% بجٹ سے زیادہ ہے۔ خام JSON، طریقہ کار، اور جو کچھ ابھی تک ناپا نہیں گیا وہ [docs/OVERHEAD.md](docs/OVERHEAD.md) میں ہے۔

## آپ کا ڈیٹا آپ کی مشین پر رہتا ہے

ClawMetry مقامی سیشن فائلیں اور لاگز پڑھتا ہے۔ **کوئی سیشن ڈیٹا آپ کے باکس سے باہر نہیں جاتا جب تک آپ `clawmetry connect` نہ چلائیں** — کوئی پرامپٹس، جوابات، ٹول آرگیومنٹس، فائل کے مندرجات یا لاگ لائنیں نہیں۔ جب آپ کنیکٹ کرتے ہیں تو، سنیپ شاٹ اُس کلید کے ساتھ اینڈ-ٹو-اینڈ خفیہ کاری شدہ ہوتا ہے جو کبھی آپ کی مشین سے باہر نہیں جاتی، اور آپ کے براؤزر میں ڈی کرپٹ ہوتا ہے۔ اگر کسی نوڈ کے پاس کوئی کلید نہیں ہے تو اپ لوڈ کو صاف حالت میں بھیجنے کے بجائے چھوڑ دیا جاتا ہے، اور کوئی بھی سرور کا جواب اسے بند نہیں کر سکتا۔

کنیکٹ کرنے سے پہلے دو چیزیں بطور ڈیفالٹ چلتی ہیں، دونوں اختیاری (opt-out) اور کوئی بھی سیشن ڈیٹا نہ لے جانے والی: ایک گمنام تنصیبی پنگ اور PyPI کے خلاف ایک ورژن چیک۔ ایک ڈیفالٹ تنصیب سٹارٹ اَپ بینر لائن کے لیے آپ کے پبلک IP کو بھی ایک بار تلاش کرتی ہے۔ ہر منزل، وہ کیا لے جاتی ہے، اور اسے کیسے بند کیا جائے، سب [docs/EGRESS.md](docs/EGRESS.md) میں درج ہے؛ سیلف-ہوسٹڈ، ری پوائنٹڈ اور ایئر-گیپڈ تنصیبات بالکل بھی کوئی اختیاری آؤٹ باؤنڈ کالز نہیں کرتیں۔

ڈی کرپشن آپ کے براؤزر میں ہوتی ہے، اس کوڈ میں جو ہم آپ کو دیتے ہیں۔ یہ پہلے صرف ایک وعدہ تھا؛ اب یہ ایک ایسی چیز ہے جسے آپ چیک کر سکتے ہیں۔ ہر لائن جو آپ کی کلید کو چھوتی ہے وہ ایک قابلِ مطالعہ فائل میں موجود ہے، [`clawmetry/static/js/cm-e2e.js`](clawmetry/static/js/cm-e2e.js)، جو ویل (wheel) کے اندر شپ ہوتی ہے اور جوں کی توں پیش کی جاتی ہے، جو ایک Subresource Integrity ہیش کے ساتھ منسلک ہے۔ یہ تصدیق کرنے کے لیے کہ براؤزر وہی چلاتا ہے جو ہم نے شائع کیا:

```bash
curl -s https://app.clawmetry.com/static/js/cm-e2e.js -o served.js
pip download --no-deps clawmetry==$(clawmetry --version | tr -d 'a-z ') -d /tmp/cm
unzip -p /tmp/cm/clawmetry-*.whl clawmetry/static/js/cm-e2e.js > published.js
diff served.js published.js && echo identical
```

یہ کیا ثابت نہیں کرتا: ہم وہ صفحہ پیش کرتے ہیں جو فائل کو لوڈ کرتا ہے، اس لیے ہم ایک مختلف صفحہ پیش کر سکتے ہیں۔ انٹیگریٹی ہیشز آپ کو ایک سمجھوتہ شدہ CDN سے تحفظ دیتی ہیں، نہ کہ فراہم کنندہ سے۔ آپ کو جو حاصل ہوتا ہے وہ یہ ہے کہ کوئی بھی تبدیلی جان بوجھ کر، صفحے کے سورس میں نظر آنے والی، اور PyPI پر موجود ایک آرٹی فیکٹ سے مختلف ہونی چاہیے جسے کوئی بھی حاصل کر سکتا ہے۔ سیلف-ہوسٹنگ یا صرف مقامی رہنا اس انحصار کو مکمل طور پر ختم کر دیتا ہے۔

## سکرین شاٹس

نیچے دیا گیا ہر عدد ایک حقیقی مشین سے ہے، صرف پڑھنے کے موڈ میں، بغیر کسی چیز کو بویا ہوا۔

**یہ آپ کو بتاتا ہے کہ کب کچھ غلط ہے، نہ کہ صرف یہ کہ کیا ہوا۔**
اوپر دو بےقاعدگی کے بینرز: خرچ روزانہ اوسط سے 7 گنا چل رہا ہے، اور لاگت میں 4.2 گنا اضافہ۔ ان کے نیچے، حالیہ 667 سیشنز میں سے 324 ضیاع کے اشارے کے ساتھ، وجہ کے حساب سے تفصیل کے ساتھ۔

![Overview: spending anomaly and cost spike banners over live agent work](https://raw.githubusercontent.com/vivekchand/clawmetry/main/screenshots/overview.png)

**یہ آپ کو دکھاتا ہے کہ پیسہ کہاں گیا، ہر ونڈو میں۔**
آج $252.47، اس ہفتے $513.15، اس مہینے $1,312.92، ہر ایک کے پیچھے ٹوکنز اور یہ کہ آپ کی سبسکرپشن اس کا کتنا حصہ پہلے سے کور کرتی ہے۔ اس کے نیچے، تقریباً $1,128/ماہ قابلِ بازیابی کے طور پر تفصیل سے، اور کیش کے دوبارہ استعمال سے پہلے ہی بچائے گئے $17,256/ماہ۔

![Cost: today, this week and this month, with an efficiency grade and itemised savings ideas](https://raw.githubusercontent.com/vivekchand/clawmetry/main/screenshots/cost.png)

**یہ دکھاتا ہے کہ ایک پیغام کیسے جواب بنتا ہے۔**
زندہ فلو خاکہ: آپ، وہ چینل جس پر یہ پہنچا، گیٹ وے، ابھی جواب دینے والا ماڈل، اور ہر وہ ٹول جس تک اس نے رسائی حاصل کی۔ نوڈز روشن ہوتے ہیں جیسے جیسے کام ان سے گزرتا ہے۔

![Flow: live diagram from you through the gateway to the model and its tools](https://raw.githubusercontent.com/vivekchand/clawmetry/main/screenshots/flow.png)

**مشین پر موجود ہر ایجنٹ، ایک جدول میں۔**
یہ کیا چلاتا ہے، پچھلے 24 گھنٹوں اور اپنی پوری زندگی میں اس کی قیمت کیا ہے، آخری بار کب دیکھا گیا، کون اس کا مالک ہے، اور آیا کوئی سبسکرپشن بل کو کور کر رہی ہے۔ یہاں 14 ایجنٹس، 3 سیشنز کام کر رہے ہیں، 13 خاموش۔

![Agents: every runtime on the machine with cost, owner, last seen and current work](https://raw.githubusercontent.com/vivekchand/clawmetry/main/screenshots/agents.png)

**یہ دکھاتا ہے کہ ایک ٹرن کا وقت اور پیسہ کہاں گیا، ٹول بہ ٹول۔**
ایک حقیقی سیشن کا ایک ٹرن: 11.2 منٹ میں 11 ٹولز، $1.16 کے عوض۔ ہر Bash کال اور ماڈل کال کو ٹائم لائن پر اپنی الگ بار ملتی ہے، تاکہ وہ کمانڈ جو 4.1 منٹ تک چلی اور وہ جو 226ms تک چلی، ایک نظر میں ہی الگ پہچانی جا سکیں۔

![Sessions: one agent turn on a timeline, every tool call with its own duration and the turn's cost](https://raw.githubusercontent.com/vivekchand/clawmetry/main/screenshots/sessions.png)

**یہ کام کا درجہ دیتا ہے، نہ کہ صرف خرچ کا۔**
اس ہفتے A: 54 کام صاف ستھرے واپس آئے، 2 سخت کاموں کی قیمت $48.57 رہی، اور وہ رنز جن میں فیصلہ کرنے کے لیے بہت کم سرگرمی تھی انہیں جیت کے طور پر شمار کرنے کے بجائے درجہ بندی سے باہر رکھا گیا۔ ہر سخت رن اپنے ٹریس سے منسلک ہے۔

![Quality: this week's report card with the rough runs and what they cost](https://raw.githubusercontent.com/vivekchand/clawmetry/main/screenshots/quality.png)

**یہ دکھاتا ہے کہ کانٹیکسٹ ونڈو کیوں بھرتی رہتی ہے۔**
تازہ ترین ٹرن پر 1M-ٹوکن ونڈو میں سے 715K، 83.3% کی چوٹی، 4 کمپیکشنز جو سب اوور فلو کے بجائے پیش بندی کے طور پر فائر ہوئیں، نیز اس کے پیچھے موجود ہر ٹرن کا استعمال۔

![Context usage: window utilisation per turn, compaction events and tokens reclaimed](https://raw.githubusercontent.com/vivekchand/clawmetry/main/screenshots/context.png)

**آپ کی جانب سے کچھ بھی ترتیب دیے بغیر ہی نشاندہی چلتی ہے۔**
تنصیب کے وقت سے ہی بلٹ-اِن ڈیٹیکٹرز آن ہیں: ایجنٹ خاموش ہو گیا، ٹیلی میٹری فیڈ رک گئی، لاگت میں اضافہ، ٹوکن میں اچانک اضافہ، خرابیوں میں اضافہ، خرابی میں اچانک اضافہ، بجٹ کی حد، خطرے کے دستخط سے میل، سیکیورٹی ٹول کی تلاش، سیکیورٹی صورتحال میں تبدیلی۔ آپ کے اپنے قواعد اوپر سے اختیاری ہیں۔

![Alerts: built-in detectors plus optional custom rules](https://raw.githubusercontent.com/vivekchand/clawmetry/main/screenshots/alerts.png)

**کسی خطرناک کال کو روکنا اختیاری ہے، اور بند حالت میں شپ ہوتا ہے۔**
Recursive deletes، force pushes، sudo، خفیہ معلومات، پیکج تنصیبات اور آؤٹ باؤنڈ کالز میں سے ہر ایک کو ایک قاعدہ ملتا ہے جسے آپ آن کر سکتے ہیں۔ جب تک آپ ایسا نہ کریں، ClawMetry دیکھتا رہتا ہے اور کچھ تبدیل نہیں کرتا۔ ایک بار آن ہونے پر، میل کھانے والی کالیں یہاں (یا آپ کے فون پر) منظوری یا انکار کا انتظار کرتی ہیں۔

![Approvals: protection rules for risky tool calls, all off until you enable them](https://raw.githubusercontent.com/vivekchand/clawmetry/main/screenshots/approvals.png)
