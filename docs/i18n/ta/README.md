## உங்கள் தரவு உங்கள் கணினியிலேயே இருக்கும்

ClawMetry உள்ளூர் அமர்வு கோப்புகள் மற்றும் பதிவுகளைப் படிக்கிறது. நீங்கள் `clawmetry connect` இயக்கும் வரை உங்கள் கணினியிலிருந்து எதுவும் வெளியேறாது. அப்போதும் கூட, ஸ்னாப்ஷாட் உங்கள் கணினியை விட்டு ஒருபோதும் வெளியேறாத ஒரு கீ மூலம் இறுதி-முதல்-இறுதி குறியாக்கம் செய்யப்பட்டு, உங்கள் உலாவியில் மறைகுறியாக்கப்படுகிறது.

## நிறுவல்

```bash
pip install clawmetry     # பின்னர்: clawmetry
```
