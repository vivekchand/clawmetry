Bring your first robot run into view

Import a Menlo SDK recording to inspect measured joints, alerts, and recorded commands.

clawmetry asimov import-recording /path/to/run.jsonl --robot-id my-asimov

Observe a connected robot

Use a Menlo Observe credential. Run the collector on the computer that can reach the robot.

clawmetry asimov observe --robot-id my-asimov --duration 60

Live observation requires Python 3.12 and the optional Menlo SDK. Read the connection guide.
