OpenClaw gateway
Only needed if you run an OpenClaw gateway. Every other runtime (Claude Code, Codex, Cursor, Aider, Goose, opencode, Qwen, …) is detected automatically — no setup required.
Local install (pip / brew / install.sh)
cat ~/.openclaw/openclaw.json | python3 -c "import json,sys;print(json.load(sys.stdin)['gateway']['auth']['token'])"
Docker install
docker exec $(docker ps -q) env | grep TOKEN
Remote / Docker / reverse-proxy
Set OPENCLAW_GATEWAY_URL=http://<host>:18789 env var, or enter the URL below.
