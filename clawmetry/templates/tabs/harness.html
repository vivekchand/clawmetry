Harness
Tools, memory, and control rules that help a model perform tasks.
What is a harness?
A model processes input and produces a response. The harness connects the model to tools, memory, and control rules. It can call the model repeatedly to perform a task. Agent runtimes such as Claude Code and Cursor provide a harness. ClawMetry shows their recorded activity. Use the links below to inspect each part. (Read about harness engineering)
🔁 The loop
An agent can read input, choose an action, use a tool, and check the result. This sequence can repeat until the agent finishes or reaches a limit.
